In this post we will build a nice React Native app and doing it will learn **React Native**. This project and post have been inspired 
by [this](https://www.youtube.com/watch?v=4nVoLX2taFg) YouTube video.

First, we need to set up a new React Native project using Expo. The **expo** documentation tells us all about it.

![](https://res.cloudinary.com/dxkxvfo2o/image/upload/v1782539517/react-native-course/1/1_iwpeiv.png)

![](https://res.cloudinary.com/dxkxvfo2o/image/upload/v1782539538/react-native-course/1/2_fdcdui.png)
